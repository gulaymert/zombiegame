# Game: Zombie Game

## Features

- **Endless Rounds:** Increasing zombie counts.
- **Smart AI:** NavMesh-based enemy tracking.
- **Combat System:** Zombie damage and attack animations.
- **Health System:** Real-time player health UI.
- **Game Flow:** Game Over and Restart mechanics.
- **UI Menus:** Main menu, Controls, and Game Over screens.
- **Pause System:** Press 'Tab' to pause/resume.
